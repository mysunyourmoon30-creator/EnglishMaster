# V1-F06 — Student Progress Overview

You own this feature end to end in the current worktree. Read `AI_RULES.md` and
the repository instructions before editing. Follow the
`clean-architecture-dotnet`, `efcore-sqlserver`, and `blazor-feature` guidance
under `.agents/skills/`. Work only inside the task contract.

## Outcome

Add an authenticated, learner-owned progress overview backed by the existing
`LessonProgress`, `CourseProgress`, and `BookProgress` tables. Expose a bounded
API summary and render it at `/learn/progress`.

This is a read-only first slice. Do not add enrollment, progress-write,
completion, certificate, or content-publication behavior. Do not add a new
entity, migration, package, scheduler, or duplicate progress store.

## Required API

- Add `GET /api/v1/me/progress?limit=20` in an authorized route group.
- Derive the user ID only from the authenticated name-identifier claim.
- Clamp `limit` to 1–50 with a default of 20.
- Return summary totals plus bounded recent lesson, course, and book progress.
- Filter every query by the current user and learner-safe active, published
  content. Never reveal another user's progress or draft/inactive content.
- Order each collection by most recent access with deterministic tie-breakers.
- Use async, cancellation-aware, `AsNoTracking`, projection-oriented EF Core
  queries without N+1 access.

## Learner Contract

Return an overall summary with:

- total tracked items, in-progress count, and completed count;
- one collection each for lessons, courses, and books;
- content type/id, slug, title, summary, learner URL, progress percent, status,
  and last-accessed time for each item.

Do not expose internal authoring fields, user IDs, storage paths, or unpublished
content metadata.

## UI

- Add `/learn/progress` under `Components/Pages/StudentProgress`.
- Show loading, error, empty, and populated states.
- Show compact totals and separate lesson/course/book sections with progress,
  status, last-accessed time, and a safe continue/open action.
- Use semantic markup, accessible labels/status text, existing component styles,
  and bilingual English/Thai labels consistent with the learning hub.
- Add discoverable links from the learning hub and learning sidebar.

## Tests

Add focused integration coverage proving:

- unauthenticated requests are rejected;
- the current user's published lesson/course/book progress is returned;
- other-user progress and draft/inactive content are excluded;
- summary counts and rich learner-safe mapping are correct;
- ordering is deterministic and the result limit is bounded;
- empty results return HTTP 200 with empty collections.

Run the contract checks, then run the full solution tests before integration.
Record remaining limitations honestly: this slice displays existing progress
records but does not create or update them.
