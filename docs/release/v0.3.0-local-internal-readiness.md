# v0.3.0 Local/Internal Readiness

## Status

`Complete - Private/Internal Local Mode`

## Purpose

Track the no-hosting operating mode selected after production go-live was deferred. This mode runs EnglishMaster on the current Windows machine only and is intended for private testing, local demos, and internal review.

## Completed Checklist

- [x] One-click local launcher exists: `Start-EnglishMaster.cmd`.
- [x] Separate API/Web launchers exist: `Start-EnglishMaster-API.cmd`, `Start-EnglishMaster-Web.cmd`.
- [x] API runs on `http://127.0.0.1:7101`.
- [x] Web runs on `http://127.0.0.1:7102`.
- [x] Local SuperAdmin bootstrap is supported through a prompted temporary password.
- [x] Default local database is persistent SQLite: `.local-internal/EnglishMasterInternal.db`.
- [x] Local media and publishing storage paths are under `.local-internal/`.
- [x] API/Web DataProtection keys are under `.local-internal/keys/` to avoid user-profile permission issues.
- [x] `.local-internal/` is ignored by git.
- [x] Documentation is updated in `docs/deployment/local-run.md`.
- [x] Production go-live remains deferred, not falsely closed.

## Local Login

| Field | Value |

Local/internal mode is complete for private use on this machine. Production go-live remains deferred until hosting is available and the production execution packet is run.
