# v0.3.0 Production Deployment Record

## Status

`Approved - Awaiting VPS Provisioning`

## Hosting Platform

`Linux VPS + Docker Compose` was selected on 2026-07-18. It uses `docker-compose.production.yml` in the repository root and the runbook at `docs/deployment/production-vps-deployment.md`.

Rationale: local-path file storage, Blazor Server long-lived connections, always-on background workers, and SQL Server fit a VPS deployment without new application architecture work. Azure App Service was considered as a managed alternative but was not chosen.
